Build the complete IOM Techs website from scratch. This is a multi-page, production-grade software company website for IOM Techs — a Nairobi-based software development startup. The site must feel like it belongs next to Vercel, Linear, and Zera Studio in terms of design maturity. Immersive, scroll-driven, alive — not a static brochure.

═══════════════════════════════════════
TECH STACK
═══════════════════════════════════════
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- GSAP + ScrollTrigger (scroll-driven animations)
- Framer Motion (component-level transitions)
- Lenis (smooth scroll)
- Lucide React (icons only, no emojis)
- next/font (Geist Sans + Geist Mono from Google)
- Deployed on Replit

Install:
npm install gsap @gsap/react framer-motion lenis lucide-react

DESIGN SYSTEM — APPLY GLOBALLY
═══════════════════════════════════════
Colors:
  --black: #000000
  --white: #ffffff
  --surface-1: #0a0a0a
  --surface-2: #111111
  --surface-3: #1a1a1a
  --border: rgba(255,255,255,0.08)
  --border-hover: rgba(255,255,255,0.18)
  --text-primary: #ffffff
  --text-secondary: #a1a1aa
  --text-muted: #52525b

Typography:
  Font: Geist Sans (headings + body), Geist Mono (code snippets, labels)
  Base: 16px
  Small: 13px (minimum — never go below)
  Lead: 18–20px
  Section headings: 48–64px desktop / 32–40px mobile
  Hero headline: 72–96px desktop / 44px mobile
  Weight: 400 body, 700 headings, 900 hero
  Letter spacing: -0.03em on large headings, 0.15em on small uppercase labels

Liquid Glass (apply to: navbar, cards, modals, floating elements):
  background: rgba(255,255,255,0.04)
  backdrop-filter: blur(24px) saturate(180%)
  -webkit-backdrop-filter: blur(24px) saturate(180%)
  border: 1px solid rgba(255,255,255,0.09)
  border-radius: 16px (cards), 9999px (pills), 12px (buttons)
  box-shadow: 0 0 0 1px rgba(255,255,255,0.04) inset,
              0 20px 40px rgba(0,0,0,0.4)
  RULE: Never stack more than 2 glass layers. Never blur over dense text.

Background — Global:
  Pure #000 base. Full-page SVG circuit/node grid overlay:
  Fine white lines at 0.04 opacity — a 60px repeating grid with node dots 
  at intersections — gives depth without color. Apply as a fixed 
  background pattern in layout.tsx so it persists across all pages.
  SVG pattern:
  <pattern id="grid" width="60" height="60" patternUnits="userSpaceOnUse">
    <path d="M 60 0 L 0 0 0 60" fill="none" stroke="rgba(255,255,255,0.04)" stroke-width="0.5"/>
    <circle cx="0" cy="0" r="1" fill="rgba(255,255,255,0.06)"/>
  </pattern>

Transitions: All interactive elements — 300ms ease-in-out
Cursor: Custom cursor — small white circle (8px) that follows mouse, 
        expands to 40px ring on hover over links/buttons. CSS only, no library.

═══════════════════════════════════════
ANIMATIONS — GLOBAL RULES
═══════════════════════════════════════
Lenis smooth scroll:
  Initialize in layout.tsx — lerp: 0.1, duration: 1.2

GSAP ScrollTrigger — apply to:
  · Every section heading: fade up from y:30 opacity:0
  · Service cards: stagger 0.1s, y:40 → y:0
  · Stats: count up from 0 when in view
  · Process steps: horizontal scroll pin
  · Project cards: stagger slide up

Framer Motion — apply to:
  · Page transitions: opacity 0→1, y:10→0, 0.4s
  · Navbar mobile menu: stagger link animations
  · Hover states on all cards
  · CTA button hover: scale 1.02

Counter animation (stats):
  Use GSAP's to() with snap:1 on a number value, 
  triggered by ScrollTrigger when stat enters viewport.

DO NOT:
  · Use any color other than black, white, and grays
  · Add gradients except black-to-transparent for section fades
  · Use any icon library other than lucide-react
  · Use emoji anywhere
  · Use placeholder lorem ipsum — write real copy throughout
  · Make any section a static non-animated block
  · Allow horizontal scroll on any screen size
  · Use background-attachment: fixed (breaks iOS)

PERFORMANCE:
  · Use next/image for all images
  · Lazy load all sections below the fold
  · GSAP animations only trigger once (toggleActions: "play none none none")
  · No animation on users who prefer reduced motion 
    (@media (prefers-reduced-motion: reduce) → disable all GSAP + Framer)

MOBILE RULES (strict):
  · html, body: overflow-x: hidden
  · All grids collapse to single column below 640px
  · Horizontal scroll process section becomes vertical on mobile
  · Touch targets minimum 44px
  · No fixed-width elements
  · Test at 320px, 375px, 768px, 1280px, 1920px
